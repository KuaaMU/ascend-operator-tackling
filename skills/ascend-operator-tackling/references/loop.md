# L2 自主循环（详细）

目标：无持续人工监督时，仍能按目标、证据、资源自主选下一步，
并主动发现自己的判断已失效。自主 ≠ 随意探索——每轮必须产生可验证信息、
缩小不确定性或改善目标指标。

## 单轮状态机

```text
REANCHOR → CLASSIFY → BASELINE → ATTRIBUTE → HYPOTHESIZE
         → PROBE → GATE → DECIDE → PERSIST → 赛马复盘点
```

### REANCHOR

WHEN 以下任一变化 THEN 先标 `stale`/`contradicted`，不沿用旧结论：
任务书/验收口径、权威分支 commit、worktree 状态、源码/二进制 hash、
目标环境版本、上一个 HANDOFF 的下一步。

### CLASSIFY

把阻碍归入唯一主类别，禁止混成"需要优化"：

| 类别 | 首选动作 |
|---|---|
| 契约/语义 | 找一手来源，写可执行 contract |
| 正确性 | 最小反例 + 独立参考实现 |
| 环境/构建 | 环境发现、干净重建、hash 对照 |
| 性能关键路径 | 归因账本、预算、结构实验 |
| 证据/状态 | provenance 修复、重新测量 |
| 工程卫生 | 隔离、清理、交付审计 |

### BASELINE

选能回答当前问题的最小基线（正确性：最小失败输入+参考实现；
性能：目标 case+当前路线+同机同构建对照；稳定性：重复运行而非单次最优）。

WHEN 复测与历史记录差异明显 THEN 先归因环境/构建/输入/测量方法，
不要先改算法。

### ATTRIBUTE

先建关键路径/误差账本，至少回答：时间/误差花在哪段？
哪段理论不可压缩（floor）？哪段受执行图/数据布局/同步限制？
哪个改动能跨多个 case 泛化？

### HYPOTHESIZE

每个候选必须可证伪，用 `scripts/new_candidate.py` 登记：
假设、唯一变量、预期方向与量级、最小区分实验、成功门、
kill criterion、回退点、可能影响的其他区间。

WHEN 一句话说不清"哪个变量会改变哪个证据" THEN 实验不成熟，
打回重写假设。

### PROBE（成本递增）

1. 静态证据：源码、hash、配置；
2. 最小运行：单 case、小批量、单阶段；
3. 方向筛选：少量样本，只判方向；
4. 正式 gate：目标口径、目标样本量、全量回归。

探针不污染生产路径；优先独立 worktree/目录。

### GATE

按类别跑 `references/gates.md` 对应门禁。Gate 是二元裁决，
不按"趋势不错"通过。

### DECIDE（五选一）

| 裁决 | 条件 |
|---|---|
| promote | 所有 gate 通过，跨区间无回归 |
| iterate | 方向正但未达门，且失败原因清楚 |
| revert | 与基线无显著差异或未达最小收益 |
| park | 当前资源不可完成但概念未证伪，写清重开条件 |
| close | 结构被多次独立证据否定，写失败家族，禁原形态重开 |

### PERSIST

至少更新 STATE、CANDIDATES、TRUTH、HANDOFF、LESSONS、METRICS；
清理本轮残留（见 `references/file-hygiene.md`）。

### 赛马复盘点

WHEN 达到约定的 N 轮（建议 5） THEN 强制看 CANDIDATES 记分牌：
kill 落后候选（见 `references/multi-agent.md`），不许单候选恋战。

## 自主纠错：结果与预测不一致

按以下顺序怀疑，不要跳过：
1. 加载了错误的构建/版本；
2. 输入、reset、warmup、采样口径或环境状态变化；
3. 实际执行路径与预期路径不一致；
4. 观测工具过滤/采样方式错误；
5. 理论模型遗漏了某类固定成本；
6. 最后才假设环境/硬件异常。

## 自主纠错：连续三次无正收益（止损）

WHEN 同一问题、同一结构连续三次满足任一 THEN 触发：
无稳定收益 / 收益只出现在单个近门限 case / 每次依赖不同参数组合 /
需扩大特例白名单才能维持收益 / 正确性证据无法闭环。

动作：①停止参数扫描 ②回退最近权威基线 ③写失败家族
④重做一次关键路径归因 ⑤只允许从新结构假设重开。

## 升级给用户

仅以下情况需要人工：验收口径有一手资料也解决不了的矛盾；
不可逆/高成本操作且无安全替代；目标资源缺失；连续多个结构家族被证伪
且无新路线。请求时附一页：当前目标、已验证事实、已关闭路线、
最小请求、两个选项与默认建议。
