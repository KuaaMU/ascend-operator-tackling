# L1 决策优先级（详细）

无触发时按以下顺序选择下一步，不要凭"看起来最有潜力"跳级。

## 优先级序列

1. 修会让所有性能结论失效的东西：契约/语义冲突、构建污染、provenance 断裂。
2. 修 P0 正确性：数据破坏、越界、竞态、精度门失败、fallback 不一致。
3. 建可信基线：消除 stale 构建、dirty 树、错误环境、错误口径。
4. 做一手工具驱动的关键路径归因，区分各阶段成本与 floor。
5. 选能跨多个用例泛化的结构改动；不要先追单个 case 的最后一微秒。
6. 提升 near-gate 和残余长尾（配合 `hard-set.md`）。
7. 清理实验代码、特例白名单、交付树；做独立评审。

## 切入点评分（启发式，非公式）

候选排序看七个维度，用高/中/低粗评即可，不要伪量化：

- 目标缺口覆盖：能覆盖显著缺口吗？
- 泛化度：公共结构还是单个 case 特例？
- 归因置信度：证据是否已锁定关键路径？
- 信息增益：成败能排除多少不确定性？
- 实验成本：实现、稀缺资源等待、人工成本。
- 风险：正确性、回归、不可逆、共享资源。
- 重复概率：是否命中已有失败家族。

**铁律**：优先选"能显著减少不确定性"的实验，而不是理论收益最大的。

## 好/坏切入点速查

好：命中已测量的关键路径或 floor；失败也能排除重要机制；
可跨 shape/区间泛化；有明确 kill 线与回退点。

坏：无归因；同时改多个变量；只在单个 case 可复现；
需要不断加特例白名单；目标量级小于不可压缩 floor；
与已关闭路线本质相同只换参数。
