# 通用失败家族

命中时先检查共同机制，不要机械套用旧结论。
用法：新问题疑似命中 → 用当前环境最小实验确认 → 命中则采用防护 →
不命中则记录区别。用例细节见 `profiles/`。

## 1. 基线失效

症状：旧日志与新源码/构建不匹配；多处各有一份产物；重建后结果整体漂移；
dirty 工作树被当作权威。
防护：记录源码/构建/测试/runner hash；确认实际加载路径；
关键结论只在可回滚状态上产生。

## 2. 摘要覆盖事实

症状：STATE 顶部写 A，底部已推进到 B；REVIEW 长期 pending 但实现继续扩展；
新 agent 从过时 checkpoint 开始。
防护：单一权威规则；gate 关闭必须更新 REVIEW；HANDOFF 每轮更新；
过期文档显式标 stale/superseded。

## 3. 参数扫描代替归因

症状：连续扫参数；每个 case 需要不同参数才过；收益不稳定、跨 run 翻转；
没有关键路径账本。
防护：先分类、测 floor；单变量实验；三次无结构收益即止损
（`loop.md` 止损节）。

## 4. 特例堆积（白名单蔓延）

症状：路由表只含测试出现过的精确条件；相邻输入落回慢路径；
每加一个 case 就加一个 if；代码通过"特例总和"而非统一模型工作。
防护：条件必须来自结构/资源模型；表 miss 自动 fallback；
加泛化用例与 holdout 回归；连续加特例 → 触发 `hard-set.md` 换路线检查。

## 5. 方差误判

症状：小样本或单次结果决定 promote；±小幅翻转被当成收益；
近门限结果缺少重复实验。
防护：方向筛选与正式裁决分开；正式 gate 用目标样本量+多次复现；
记录跨 run 方差；近门限留 margin。

## 6. 未验证的中途结论

症状：从理论/文档直接得出 GO；结论进 STATE 后无人再实验；
后续 agent 在其上叠加。
防护：标 `assumed`/`unverified`；写最小验证与 kill 线；
promote 前必须目标环境证据。

## 7. 上下文断层

症状：新 agent 重复失败实验；找不到最后一条可执行命令；
只留聊天结论；不知道当前构建与分支。
防护：HANDOFF 单一恢复路径；候选关闭/重开条件；hash 与环境快照；
最小 smoke 复验。

## 8. 工程污染

症状：生产树遗留探针/dump；`.orig/.bak` 备份；未接线代码；
根构建混入实验依赖；测试专用代码进入生产库。
防护：生产/实验 worktree 隔离；交付前 allowlist；
clean build；diff 审查。
