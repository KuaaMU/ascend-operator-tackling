# Review

本文件只由独立 Reviewer 填写。Reviewer 不读取 Driver 的自我结论，只读取交付物、出口标准、
原始证据和任务契约。

## P0 / P1 / P2

| Level | Meaning |
|---|---|
| P0 | 结果错误、破坏数据/环境、违反契约、目标环境不可运行、不可复现 |
| P1 | 边界失败、性能未达、证据缺失、泛化不足、文档与代码不一致 |
| P2 | 结构、命名、可读性、非阻断维护问题 |

存在任一 P0/P1 则不通过。
